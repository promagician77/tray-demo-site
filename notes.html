Build Notes

Photo-to-Tray Pipeline — Technical Prototype

How to run from source

# Clone and install (all MIT/Apache-2.0)
pip install manifold3d trimesh pyclipr shapely numpy scipy Pillow
pip install opencv-python-headless    # optional: for real photo path

# Run with synthetic test objects
python pipeline.py --synthetic --output out/

# Run with a real photo
python pipeline.py --image photo.jpg --output out/ --object-height 25

# Force split for small bed
python pipeline.py --synthetic --bed-size 150 --output out-split/

Architecture decisions

manifold3d for CSG — Apache-2.0/MIT dual license, guaranteed watertight output by construction (the only CSG library that makes this guarantee), Clipper2 built in for 2D cross-sections. MeshLib is faster on 2M-triangle meshes but LGPL; CGAL is GPL. manifold3d is the only option that satisfies the "MIT/Apache-2.0 only" constraint and produces correct results reliably.

MobileSAM over U2-Net or BiRefNet — MobileSAM's encoder is 5M parameters (~27 MB ONNX), inference ~80 ms on CPU, and it handles the hard segmentation cases (shadows, pale handles, reflective metal) because it uses a vision transformer rather than pixel-level saliency. The weights are Apache-2.0. U2-Net is Apache-2.0 but produces salient-object maps, not instance masks — you can't distinguish two adjacent tools. BiRefNet weights (RMBG-2.0) are non-commercial.

Dovetail joints over puzzle-piece or snap-fit — Dovetails are self-aligning (the taper guides assembly), strong along all axes, and printable without supports. The 15% taper per side gives a 7.5° angle, well within FDM's ability. Puzzle-piece (jigsaw) joints require supports for the undercuts; snap-fit requires elasticity that PLA lacks.

Key equations

Parallax correction:
  corrected_point = point − (point − sheet_center) × (object_height / camera_height)
  For h=25mm, cam=400mm: correction ratio = 6.25%
  Edge point at 107mm from center: 6.7mm inward correction

Homography (OpenCV):
  H = findHomography(src_corners_px, dst_corners_mm)
  warped = warpPerspective(image, H, (sheet_w_mm, sheet_h_mm))

Dovetail geometry:
  tooth_width = 10mm, gap = 6mm, taper = 15%/side
  narrow_end = tooth_width × (1 − 2 × 0.15) = 7mm
  clearance = 0.2mm/side (FDM), 0.1mm/side (SLA)
