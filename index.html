What this pipeline does

A single Python script takes a top-down smartphone photo of objects on a calibrated 8.5×11″ sheet and outputs:

  • Watertight .STL meshes — one tray or 4 interlocking quadrants with dovetail joints if it exceeds the print bed
  • 2D .SVG vector paths — for laser cutting or CNC routing
  • A JSON measurement report — every step timed, every mesh verified

Pipeline stages

1. Homography & Scale

OpenCV detects the 4 corners of the reference sheet, computes a perspective homography to rectify the image into true mm coordinates, and establishes the mm/px scale factor. The sheet size (8.5×11″ or A4) is configurable.

2. Z-Height Parallax Compensation

A 25 mm-thick metallic object on white paper shifts outward from the optical axis due to perspective. The pipeline corrects each contour point by the ratio object_height / camera_height, shrinking the contour toward the sheet center. This is essential for thick or tall objects under normal room-height smartphone photography.

3. Segmentation

Two paths: Demo OpenCV adaptive threshold + morphological close for high-contrast objects on white paper. Production MobileSAM via ONNX Runtime — Apache 2.0 licensed weights (~27 MB encoder + ~16 MB decoder), runs on CPU, handles cast shadows, reflective surfaces, and pale handles that fool thresholding.

4. Contour Cleaning (Clipper2)

Raw contours are simplified (Douglas-Peucker), then offset outward by a configurable clearance (default 1.5 mm) using pyclipr's Clipper2 engine with round joins. Self-intersections are repaired automatically.

5. Finger Recesses

Semicircular notches (default r=12 mm) are added on opposite sides of each object's graspable axis so the user can lift the object out of the tray.

6. CSG Tray Generation

The tray shell is a rounded rectangle extruded to floor + cavity depth. Each cleaned contour is extruded and boolean-subtracted from the shell using manifold3d's CSG engine. All operations produce guaranteed-manifold, watertight meshes.

7. Interlocking Dovetail Joints

When the tray exceeds the configured print bed size, the pipeline splits it into a 2×2 grid. Each seam gets alternating trapezoidal (dovetail) teeth that protrude from one side and socket into the other. All joints extrude vertically, so the 4 pieces slide together in the XY plane without geometric blocking. Clearance is configurable (default 0.2 mm/side for FDM).

8. Export

Binary STL with corrected normals via trimesh. SVG with mm-unit viewBox, tray outline, and cutout paths. JSON report with vertex/face counts, watertight status, volume, bounding box, and per-stage timing.

Shadow & parallax handling

Cast shadows are the #1 failure mode for threshold-based segmentation on white paper. The production path uses MobileSAM (segment-anything with a 5M-parameter TinyViT encoder), which segments by semantic understanding rather than pixel intensity — it correctly isolates a chrome wrench from its shadow because it knows the shadow is not an object. The ONNX export runs on CPU in ~80 ms per image.

Z-height parallax from a 25 mm-thick object at 400 mm camera height produces ~6% radial distortion at the sheet edges. The pipeline applies a per-point correction: corrected = point − (point − sheet_center) × (obj_h / cam_h). This brings a 6 mm edge error down to <0.5 mm without camera calibration.

Pale-handled objects on white paper have near-zero contrast under threshold. MobileSAM handles this because its encoder sees texture and edge gradients, not just luminance difference. For the OpenCV fallback, CLAHE contrast enhancement + adaptive thresholding with a large block size recovers most edges.

Dovetail joint assembly order

When splitting into a 2×2 grid, geometric blocking is avoided by making all joints vertical extrusions (constant cross-section in Z). The assembly works in any order:

  1. Place any quadrant face-down on the table
  2. Slide any adjacent piece into its dovetail teeth from the XY plane
  3. The tapered trapezoid locks once fully seated (15% taper per side)
  4. Repeat for the remaining two pieces

No piece blocks another because every joint axis is perpendicular to Z — there is no "first piece" constraint. The 0.2 mm per-side clearance is tuned for FDM (PLA/PETG); SLA prints would use 0.1 mm.

Packaging for offline Windows .exe

The production build uses PyInstaller (or Nuitka) to bundle Python, OpenCV, ONNX Runtime, manifold3d, and the MobileSAM ONNX weights into a single-folder distribution. The folder includes:

  • tray-maker.exe — entry point
  • models/mobilesam_encoder.onnx + mobilesam_decoder.onnx (~43 MB)
  • All .pyd/.dll files for numpy, OpenCV, ONNX Runtime, manifold3d
  • An NSIS or WiX installer wraps the folder into a standard Windows installer

Total installed size: ~180 MB. No network required at runtime. An independent reviewer can pip install -r requirements.txt && python pipeline.py --synthetic to build and verify from source on a clean PC.
